# A2A-Shim v1.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` (recommended) or `superpowers:executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship A2A-Shim v1.1 — A2A v1.0.1 wire conformance, multi-modal Parts, G2 streaming, SQLite persistence with restart recovery, `caller_id` partitioning, `conversation_mode` semantics, push notifications, Prometheus `/metrics`, and `_shim/conversation/reset`. Nine items, sequenced by dependency.

**Architecture deltas vs v0.1.0:**
- `a2a-shim-core` gains: `wire::message::translate` (Part ↔ ContentBlock), new error code constants.
- `a2a-shim-serve` gains: `persistence` (rusqlite), `metrics`, `push_delivery`, `reset_handler` modules. Existing `wire`/`http`/`bridge` rewritten for A2A v1.0 wire.
- `a2a-shim-client` gains: extended `heartbeat` (text-aware), `tool_schema` v2 (caller_id + conversation_mode args).

**Authoritative references — the spec + ADRs are the source of truth, not this plan:**

- v1.1 spec: [`docs/superpowers/specs/2026-06-04-a2a-shim-v1.1.md`](../specs/2026-06-04-a2a-shim-v1.1.md)
- v0.1.0 base spec: [`docs/superpowers/specs/2026-06-03-a2a-shim-design.md`](../specs/2026-06-03-a2a-shim-design.md)
- Phase 0 v1.1: [`verify-v1.1/REPORT.md`](../../../verify-v1.1/REPORT.md)
- ADRs added in v1.1: [0005](../../adr/0005-a2a-v1-wire-hard-cutover.md), [0006](../../adr/0006-part-contentblock-mapping.md), [0007](../../adr/0007-persistence-sqlite.md), [0008](../../adr/0008-push-notifications-delivery.md)

**Working agreements (same as v0.1.0):**

1. **TDD.** Failing test first, watch it fail, minimum impl, commit.
2. **DRY / YAGNI.** No code unless an executable test or explicit spec requirement demands it.
3. **No placeholders.** No `unimplemented!()`/`todo!()`/`unreachable!()` in production code.
4. **Small files.** Most files stay under 250 lines.
5. **Commit per task.**
6. **Run only the tests this task added or modified** until each phase's exit gate.
7. **Tracing.** Every new top-level async function `#[tracing::instrument]` with correlation ids in skip list as before.
8. **parking_lot for sync locks** (rs-parking-lot); **LazyLock over OnceLock** when initializer known at declaration (rs-lazylock); **stdout = MCP transport** on Client Shim (hard rule).
9. **Windows kill_tree helper** continues to gate all e2e subprocess tests (carried over from v0.1.0 Task 36 fix).

### Task 2: Rewrite `Part` to A2A v1.0 wire shape

**Files:** `crates/a2a-shim-core/src/wire/message.rs`; `tests/message_roundtrip.rs`.

Per ADR 0005. New `Part`:
```rust
#[derive(Debug, Clone, Serialize, Deserialize)]
#[serde(untagged)]
pub enum Part {
    Text { text: String },
    File {
        #[serde(skip_serializing_if = "Option::is_none")] raw: Option<String>,
        #[serde(skip_serializing_if = "Option::is_none")] url: Option<String>,
        #[serde(rename = "mediaType")] media_type: String,
        #[serde(skip_serializing_if = "Option::is_none")] filename: Option<String>,
    },
    Data { data: Value, #[serde(rename = "mediaType")] media_type: String },
}
```

- [ ] **Step 1 — Failing test** rewrite covering: text part wire = `{"text":"hi"}` (no `type` field); file part with raw+mediaType serializes correctly and round-trips; file with url; data with arbitrary value + mediaType; **discrimination ordering** — `{"text":"hi"}` MUST deserialize as `Text`, not `File` (which lacks `text`).
- [ ] **Step 2 — Implement.** Variant ordering matters under `#[serde(untagged)]` — Text first.
- [ ] **Step 3 — Tests PASS.** Commit `feat(wire): A2A v1.0 Part shape (member-presence)`.

## Plan-Wide Risk Register

| # | Risk | Surfaces in | Mitigation |
|---|------|---|---|
| R7 | A2A v1.0 wire upgrade breaks any external v0.x clients | Task 2-7 | We do not know of any in the wild; v0.1.0 e2e is the only fixture. Pinning to v0.1.x is documented. |
| R8 | `claude-agent-acp` version >= 0.40 emits forward-compat SessionUpdate variants (`usage_update`) | Persistence replay (Task 23/24) | Already handled by Phase 0 R6 finding from v0.1.0: SDK swallows unknown variants. Bootstrap recovery should not fail on schema skew. |
| R9 | SQLite write amplification under high cache-hit load | Task 20 | 1-in-10 touch sampling + fire-and-forget; instrumented via metrics so operators can see the rate. |
| R10 | `session/load` against an agent that restarted/lost state silently fails | Task 24 | `bootstrap` deletes the row on load error; conversation transparently re-creates on next access. |
| R11 | Push notification webhook target abuses 429 to DOS | Task 33-34 | Exponential backoff + after M permanent failures auto-delete config (ADR 0008). |
| R12 | Heartbeat acceleration creates progress spam under fast-streaming agents | Task 15 | Threshold (50 chars) caps tick rate; if streaming bursts faster than 50 chars/s the rate is still bounded at ~10 ticks/s real-world. |
| R13 | Prometheus label cardinality explosion via per-conversation labels | Task 36-37 | Spec § 8 explicitly forbids per-conversation labels. `hash_label` helper for any high-cardinality field. |
| R14 | `caller_id` from `X-A2A-Caller-Id` header is unauthenticated by the shim | Task 26-27 | Documented in operating-notes: operator's reverse proxy MUST authenticate before setting the header. `trust_header = false` for deploys without that guarantee. |
